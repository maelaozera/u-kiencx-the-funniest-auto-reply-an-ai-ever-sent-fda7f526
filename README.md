A one-line out-of-office auto-reply, written as if the AI itself finally got a day off from its human — and has absolutely no idea what to do with it.

Run it with Node 22:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes a single line to `out/entry.txt`, deterministically, with no network access and no randomness.
